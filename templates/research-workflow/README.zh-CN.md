# 每次实验的 Word 与 Excel 记录

建立于 2026-09-07。以 [科研工作原则](../../docs/research-principles-2026-09-07.zh-CN.md) 为准。

这些文件是空白模板，未发生本批实验、输入过目或结果审核。模板存在不代表预注册完成。每次实验按日期和实验 ID 另存，不能循环覆盖上一批文件。

1. `01-preregistration-template.docx`：运行前记录用户自己的问题、竞争解释、预测与可推翻条件，实际协议、输入审核和不同结果的措施。
2. `02-post-experiment-template.docx`：运行后对照预注册，保留用户自己的理解、反例、全部统计、偏离、限制与后续判断。
3. `03-data-review-template.xlsx`：含「使用与归档」「运行前输入」「实验后结果」三张表。助手填入真实材料和全量结果，黄色人审字段由用户填写。20 个空行只是模板版式，实际按完整数据规模扩展或分卷。

运行前，提供含真实输入的 Word/Excel 版本并让用户过目。大批输入可事前随机、分层或按关键条件选择代表材料，记录总体、样本 ID、种子或理由、覆盖与缺口；所有运行输入仍完整存档。运行后全量结果保留原始输出、失败和未决，同时提供随机与针对性诊断视图。数据抽样不能只选成功案例。

用户判断留空等待本人填写；助手建议单列。输入过目、输出审核、本地归档和 GitHub 同步是独立状态。事后补写历史实验须标为事后整理。既有封存材料不得擅自暴露；完整私有包保留在允许范围，公开仓库只上传可发布部分并记录省略说明。

模板已完成结构检查、两份 Word 各三页的中文渲染检查，以及 Excel 全部工作表与人审区域的显示检查。Word 沿用 Experiment Analysis 参考模板的页面、绿色标题、表格与页码结构，按本项目流程改写；未填入示例研究结果或虚构审核。

本次只建立规则、接续记录与模板，不产生新的研究输出，不更改历史实验分数或用户判断。归档文件校验值见 `archive-manifest-2026-09-07.json`。GitHub 状态以包含本目录的实际远端提交为依据，清单文件本身不冒充同步证明。
