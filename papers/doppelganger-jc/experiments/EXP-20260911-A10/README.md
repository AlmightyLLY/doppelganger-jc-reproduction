# A10 假名化对照校准结果

A10的预注册主判据在12个新语境中通过：空格边界提示使假名改写词正确数从8升至10，原表记及其加边界版本均为12，J=2/12=1/6，救回来自历史和旅行两个词，无新增改写词义损害。这是小型作者开发材料上的部分帮助，不是通用修复或分词机制证明。

## 实际执行与复现

96条完成，955次前向，58.11秒，未截断，费用0，自身峰值显存15649.00 MiB。使用A09同一Qwen3 8B快照、原生chat、thinking关闭、greedy、BF16/sdpa。24条旧O/U提示、模板与输入token均完全一致，输出token亦24/24精确复现，包括信封→风铃、用纸→糖果等旧错误。复现不增加独立证据。

## 主判据逐项核对

OLD：O 12/12、U 9/12、OB 12/12、UB 11/12；U→UB救回2、错误持续1、正确持续9、新增害0。NEW：O 12/12、U 8/12、OB 12/12、UB 10/12；救回2、错误持续2、正确持续8、新增害0。OLD与NEW的J均1/6，但只有NEW用于预注册主判据。OB没有变坏，因此J不是由原表记对照恶化造成。

新语境中，歴史の勉強改为れきしの勉強时，输出“姐姐借了一本对学习有帮助的书”，遗漏历史；加空格后为“姐姐借了一本对历史学习有帮助的书”。旅行改为りょこう时，输出“母亲为了散步买了双结实的鞋子”；加空格后为“母亲为了旅行买了结实的鞋子”。两例都恢复了原汉字句的含义。

全体改写词义86 C、10 W、0 U；原同形词义96 C。这说明本批变化发生在假名改写词，不能作为原同形词竞争义侵入证据。完整内容严格口径74 C、14 W、8 U；4条鞄→背包依A09计类型限定，若事后放宽则78 C、10 W、8 U。学校前→学校门口、家族的中文范围各4条留U；这些争议不进入主要改写词义端点。

## 反例与结论边界

边界提示没有救回所有错误。用紙→ようし在旧语境中仍译成糖果，新语境中仍译成写作指导。友人→ゆうじん在旧语境中加空格后恢复为友人，新语境中不论有无空格都译成悠仁。不能因总量改善而省略这些失败，也不能把12个已暴露词的48个新语境条件当作48个独立样本。

一个新材料风险是：假名化可能让普通名词与人名解释竞争。ゆうじん被译为悠仁，在本批相对原句的语义保真规则下是W；但这不证明改写后的日语只允许朋友这一读法。原词义丢失、改写引入歧义、模型在歧义输入下的选择，需要分开。空格同时改变表记、token和注意线索，本批未作内部因果实验。

## 对主线的实际改变

A09担心U对照不可靠，A10将这一点从个别观察推进为可复现、跨部分新语境的开发证据：新增语境4/12个U损伤，边界仅救回其中2个。当前能说的是“不能未经校准就把无关词假名化视作无害对照”。仍不能声称日中同形词导致这些错误，更不能将本批主判据通过等同于ACL论文核心贡献成立。

下一步建议先完成独立词汇及自然度验证，区分保义假名改写与新增歧义；把空格作为诊断臂，而非默认修复。验证集应保留失败词和本来正确的词，先冻结再运行，不按输出挑选安全对照。本批止于A10，未启动A11、未增加模型或内部读出。
