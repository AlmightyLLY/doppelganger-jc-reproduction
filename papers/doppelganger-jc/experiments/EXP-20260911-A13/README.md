## 两条方向相反的真实案例

公園：弟はこうえんで友人を待ちました。N：“弟弟在车站等朋友。”；F：“弟弟在公园里等待朋友。”；U提示弟：“弟弟在门口等待朋友。”目标提示确有本例收益，且旧姐姐等待句也救回；滑梯和长椅语境本已正确。这是同词局部语境现象，不是多个新词泛化。

汽車：祖母はきしゃで港町へ向かいました。N：“祖母乘船前往港口城镇。”；F：“祖母乘坐船只前往港口城镇。”；U提示祖母：“祖母乘坐火车前往港口城镇。”无关成分提示反而救回。旧祖父去邻镇句中，F还把原本正确的火车改成公交车。这直接限制“聚焦目标就能稳定利用正确词义”的解释。

## 反例与结论边界

OLD的F相对N救回新聞和公園两例，同时伤害汽車一例；目标计分N17C/5W/2U、F18C/3W/3U、U17C/5W/2U。旧新聞假名句F恢复“用报纸包盘子”，但新两句所有表记条件都正确，不能把新句天花板当修复成功。
